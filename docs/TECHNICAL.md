# WinterDesk ❄️

데스크톱 위에 눈이 내리고, Dock 위에 쌓인 눈으로 눈사람을 만들 수 있는 macOS 메뉴바 앱입니다.
외부 에셋 없이 모든 그래픽을 코드로 그립니다 (SpriteKit + Core Graphics).

## 빌드 / 설치

```bash
./build.sh      # build/WinterDesk.app 생성 (swiftc, Xcode 불필요, ad-hoc 서명)
./install.sh    # 빌드 → 기존 인스턴스 종료 → ~/Applications/WinterDesk.app 로 ditto 복사 → open
```

### 로그인 시 자동 실행

`~/Applications` 에 설치된 앱은 첫 실행 때 한 번 "Launch at Login"이 자동으로 켜집니다.
먼저 `SMAppService.mainApp` 으로 등록하고, ad-hoc 서명이라 실패하거나 승인 대기(`requiresApproval`)이면
`~/Library/LaunchAgents/com.local.winterdesk.plist` (RunAtLoad, **KeepAlive 없음**, Aqua 세션만)를 대신 씁니다.
메뉴의 "Launch at Login" 체크는 실제로 활성화된 방식을 반영하고, 체크를 끄면 등록과 plist를 모두 지웁니다.
로그인 실행도 일반 실행과 같은 안전 장치(센티널 안전 모드, 잠금/잠자기 중 오버레이 없음, 워치독)를 거칩니다.

## 단축키 (어디서나, 손쉬운 사용 권한 불필요)

| 키 | 동작 |
|---|---|
| ⌃⌥⌘Q | 비상 종료 (즉시) |
| ⌃⌥⌘E | 효과 전체 켜기/끄기 (Effects On) |
| ⌃⌥⌘S | 눈 내리기 켜기/끄기 |
| ⌃⌥⌘D | 산타 켜기/끄기 |
| ⌃⌥⌘L | 전구 연결하기 (메뉴 맨 위 "전구 연결하기…") 켜기/끄기, 편집 중 Esc로 종료 |
| ⌃⌥⌘P | 제설차 켜기/끄기 |

메뉴바 ❄️ 아이콘이 노치에 가려 안 보이면 ⌘를 누른 채 아이콘을 드래그해 옮길 수 있고, 위치는 기억됩니다.
아이콘이 안 보여도 위 단축키는 항상 동작합니다.

요구 사항: macOS 13+, Command Line Tools (Swift 5.9+).

## 사용법

- **눈사람 만들기**: Dock 위(또는 화면 아래) 눈을 클릭하고 좌우로 드래그하면 눈덩이가 굴러가며 커집니다.
  눈이 없는 곳에서는 커지지 않습니다. 작은 눈덩이를 큰 눈덩이 위에 놓으면 쌓입니다 (최대 3단).
  2단부터 얼굴이, 3단이면 단추가 생깁니다. 아래 공을 끌면 눈사람 전체가 이동하고, 위 공을 끌면 분리됩니다.
- **눈덩이/눈사람 지우기**: 눈덩이 위에 0.3초 정도 올려 두면 맨 위 공의 왼쪽 위에 ✕가 나타납니다. ✕를 누르면 그 공
  (과 그 위의 공들)이 사라지고, 맨 아래 공이면 눈사람 전체가 사라집니다 (눈은 바닥 눈으로 돌아감). 오른쪽 클릭 → "삭제"도
  같습니다. 메뉴의 "Clear Snowballs & Snowmen"은 눈덩이만, "Clear Snowmen, Snowballs & Gifts"는 선물까지 지웁니다.
- **눈사람 꾸미기**: 완성된 눈사람(2단 이상)을 클릭하면 "Fashion week, but colder." 패널이 열립니다.
  Hat / Face / Body / Clothes 탭에서 고르면 바로 적용되고, 눈사람마다 따로 저장됩니다. ↺ 초기화, ✕ 닫기 (Esc도 가능).
- **산타**: 썰매와 순록 3마리가 가끔 하늘을 가로질러 날아가고, 때때로 Dock 위에 착지해 미끄러지다 다시 날아오릅니다.
  산타를 클릭하면 "Ho Ho Ho!" 와 함께 선물을 떨어뜨립니다. 드래그해서 옮길 수도 있습니다.
- **선물**: 기본으로 빨간 선물 상자 하나가 Dock 위 눈의 왼쪽 1/3 지점에 놓입니다 (Dock을 못 찾으면 바닥 눈 위).
  산타가 지나갈 때마다 약 20% 확률로 정확히 하나를 떨어뜨리고(산타를 클릭해도 하나), 선물은 계속 쌓입니다.
  자동으로 사라지지 않으며 ✕ 삭제, 더블클릭(열기), "Clear Snowmen & Gifts"로만 없어집니다. 최대 30개이고, 가득 차면
  산타가 더 떨어뜨리지 않습니다(오래된 선물을 지우지 않음). 상자는 최대 3단까지 쌓이고, 더 높거나 비스듬히 얹힌 상자는
  옆으로 미끄러져 Dock 끝에서 바닥 눈으로 떨어집니다. 선물(위치·색·기본 선물 여부)은 저장되어 다음 실행과 오버레이 재생성 때
  복원됩니다(5초마다 변경 시, 종료 시 저장). 기본 선물을 지우거나 열면 그 세션에서는 다시 놓이지 않고, 저장된 기본 선물이
  없으면 다음 실행 때 하나 놓입니다. 메뉴의 "Add Gift"로 Dock 위에 하나 더 떨어뜨릴 수 있습니다.
  드래그해서 던질 수 있고, 마우스를 올리면 왼쪽 위에 ✕ 삭제 버튼이 나타납니다.

- **창 위 눈**: 화면에 보이는 앱 창의 윗변마다 얇고 깨끗한 눈 띠(4–8pt, 살짝 울퉁불퉁, 모서리에 작은 둥근 처마)가
  아주 천천히 쌓입니다. 앞쪽 창에 가려진 부분은 그리지 않고, 클릭은 가로채지 않습니다.
  - **실시간 창 추적(실험적, 기본 켜짐)**: macOS 비공개 SkyLight 창 이동/크기 알림을 받아, 창을 끄는 동안 눈 띠·전구·
    창 위 눈사람이 창과 정확히 함께 움직입니다. 빠르게 움직이면 작은 눈덩이(3–8pt)가 튀어 떨어져 바닥/Dock 눈에
    쌓이고, 눈사람은 살짝 흔들리며, 아주 세게 흔들 때만 튕겨 떨어집니다. 알림 기능을 쓸 수 없거나 2초 안에 알림이
    오지 않으면 자동으로 **기본 모드**로 바뀝니다 (메뉴에 "창 추적: 실시간 / 기본" 표시).
  - **기본 모드**: 창을 잡아 움직이면 눈이 조각으로 미끄러져 떨어지고, 0.4초 멈추면 새 위치에 다시 쌓입니다.
    앞뒤 순서만 바뀌거나 높이만 바뀌는 경우(검색창 자동완성 등)에는 아무 일도 일어나지 않습니다.
- **창 위 눈사람**: 처음 실행하면 맨 앞 큰 창 윗변에 산타 모자를 쓴 작은 눈사람(약 40pt)이 하나 서 있습니다
  (창이 없으면 Dock 위). 눈사람이나 눈덩이를 창 윗변에 올려 두면 그 창에 붙어 함께 다니고, 다른 창이 앞을 가리면
  숨겨집니다. 창 위 눈사람의 위치는 앱 번들 ID + 창 순번 기준으로 저장되어 다음 실행 때 복원됩니다.
- **제설차 (⌃⌥⌘P, 메뉴 "제설차")**: 노란 장난감 제설차가 바닥/Dock 위 눈을 천천히 달리며 눈을 밀어 작은 더미를
  만들고, 끝이나 Dock 경계에서 돌아섭니다. 드래그해서 옮길 수 있고, 클릭하면 경광등이 켜지거나 꺼지며 "빵!" 하고 튑니다.
- **창 전구 장식**: 각 창 윗변의 가랜드("Window Garlands")와, "Light Links: Automatic"일 때 가까운 두 창 사이의
  자동 전구 줄이 걸립니다 (전구 최대 150개). 창을 잡아 움직이면 그 창의 전구는 아래로 처지며 사라졌다가, 창이 멈추면 새 위치에서 다시 나타납니다.
- **전구 직접 연결 (⌃⌥⌘L 또는 메뉴 맨 위 "전구 연결하기…")**: On Top 모드나 Window Lights가 꺼져 있으면 자동으로
  켜고 알려 줍니다. 들어가면 화면 위쪽에 움직이는 설명(점 → 점 드래그 애니메이션, "알겠어요" 버튼만 클릭 가능,
  8초 뒤 작은 안내로 바뀜)이 뜨고, 보이는 창 윗변 왼쪽/가운데/오른쪽에 깜빡이는 **금색 점**이 나타납니다.
  점(반경 약 12pt)만 마우스를 받고 나머지는 그대로 클릭이 통과합니다. 금색 점을 다른 창의 금색 점으로 끌면
  미리보기 전선이 따라오고, 40pt 안의 연결 가능한 점에 자석처럼 붙으며 그 점이 커집니다(연결할 수 없는 점은 빨간색).
  놓으면 전구 줄이 생기고, 점 근처가 아닌 곳에서 놓으면 취소됩니다. 보이는 창이 2개 미만이면 안내가 뜹니다. 같은 창끼리, 이미 있는 연결, 가려진 지점은 거부되며 최대 20줄입니다. 편집 중 줄을 클릭하면 삭제됩니다.
  Esc, ⌃⌥⌘L, 또는 30초 동안 조작이 없으면 편집이 끝납니다. 효과가 꺼져 있거나 화면이 잠겨 있거나 안전 모드면 무시됩니다.
  연결된 창이 닫히면 그 줄도 사라집니다. 첫 연결을 만들면 한 번 "Manual only"(자동 연결 끔)로 바뀝니다.
  연결은 앱 번들 ID + 그 앱의 창 순번 + 지점 종류로 저장되어, 다음 실행 때 양쪽 창이 각각 하나로만
  정확히 대응될 때 복원됩니다 (그 외에는 조용히 건너뜀).

## 비상 종료 / 안전 모드

- **⌃⌥⌘Q (Control+Option+Command+Q)**: 어떤 앱이 앞에 있어도 WinterDesk를 즉시 종료합니다
  (Carbon 전역 단축키, 손쉬운 사용 권한 불필요). WinterDesk는 메뉴바 전용 앱이라 강제 종료(⌥⌘Esc) 목록에 나오지 않습니다.
- **안전 모드**: 실행할 때 ⇧(Shift)를 누르고 있거나 `--safe` 인자로 실행하면 Desktop 모드 + 창 위 눈/전구 꺼짐으로 시작합니다.
  직전 실행이 정상적으로 10초를 넘기지 못했거나(강제 종료, 멈춤, 재부팅) 안전 장치로 종료됐다면 다음 실행은 자동으로
  안전 모드가 되고 메뉴 맨 위에 ⚠️ 안내가 표시됩니다. 메뉴에서 Mode를 직접 고르면 안전 모드가 끝납니다.
- **워치독**: 백그라운드 타이머가 메인 스레드가 3초 이상 멈추거나 장면 노드 수 / 가산 블렌딩 스프라이트 크기가
  한도를 넘으면 오버레이를 투명·클릭 통과로 만든 뒤 앱을 종료합니다.
- **화면 잠금/디스플레이 잠자기**: 잠자기·잠금 중에는 오버레이를 만들지 않고(있으면 내림), 깨어나거나 잠금 해제되면 새로 만듭니다.
- **⌃⌥⌘S (Control+Option+Command+S)**: 눈 내리기 켜기/끄기 (메뉴의 "Snow Falling"과 같음, 상태는 저장됨).
  끄면 새로 내리거나 쌓이지 않고, 이미 쌓인 눈은 그대로 남습니다. 전환할 때 화면 위쪽 가운데에 잠깐 안내가 뜹니다(클릭 통과).
  메뉴바 ❄️ 아이콘이 노치에 가려 보이지 않을 때 유용합니다.
- **⌃⌥⌘D (Control+Option+Command+D)**: 산타(썰매와 순록) 켜기/끄기 (메뉴의 "Santa"와 같음, 상태는 저장됨).
  끄면 날고 있던 산타가 0.5초 동안 서서히 사라지고 더 이상 나타나지 않으며, 켜면 약 3초 뒤에 다시 날아옵니다.
  전환할 때 같은 안내가 잠깐 뜹니다.
- `--diag`: 창 위 눈 진단 로그를 `~/Library/Logs/WinterDesk/diag-<시각>.csv` 에 남깁니다 (grab / slideOff / regrow,
  마우스·폴링 이벤트, 시작 시 권한/주사율 정보). 1초마다 백그라운드에서 기록합니다.
- `--test-seconds N`: N초 뒤 자동 종료(메인 스레드가 멈춰도 워치독이 종료). 감독 하의 실기 테스트용.

## 메뉴바 (❄️)

Effects On (⌃⌥⌘E, 맨 위) · Snow Falling (⌃⌥⌘S) · Snow Intensity (Light/Normal/Heavy) · Mode (Desktop / On Top) · Santa (⌃⌥⌘D) ·
Snow on Windows · Window Lights · Edit Lights… (⌃⌥⌘L) · Light Links (Automatic / Manual only) · Window Garlands ·
Light Style (Multicolor / Warm White) ·
Add Gift · Clear Snowballs & Snowmen · Clear Snowmen, Snowballs & Gifts · Reset Snow · Grant Accessibility for Dock snow · Launch at Login · Quit ·
Emergency quit 안내(⌃⌥⌘Q)

- **Effects On**: 끄면 모든 오버레이 창과 꾸미기 패널을 닫고 60Hz 마우스 폴링·창 추적·Dock 타이머를 멈춥니다
  (CPU 거의 0). 메뉴바 아이콘(흐리게 표시)과 단축키만 남습니다. 끄기 전에 선물을 저장하고, 다시 켜면 복원합니다.
- **Desktop 모드**(기본): 데스크톱 아이콘 바로 위 레벨이라 앱 창 뒤에 보입니다 (창 위 눈/전구는 꺼짐).
- **On Top 모드**: 모든 일반 창 위에 오버레이가 놓입니다. 창 위 눈과 전구는 사용자가 Mode 메뉴에서 이 모드를
  직접 고른 경우에만 동작합니다 ("Snow on Windows"/"Window Lights"를 켜도 모드가 자동으로 바뀌지 않습니다).

## 창 추적

`CGWindowListCopyWindowInfo` 로 화면에 보이는 앱 창(레이어 0, 120×80 이상, WinterDesk 자신 제외)의 위치만 읽습니다
(화면 기록 권한 불필요, 창 제목은 사용하지 않음). WinterDesk 자신의 모든 창(PID와 창 번호 모두)은 제외하고, 최대 40개까지만 추적합니다. 전체 목록은 창이 움직이는 동안 초당 10회, 가만히 있으면 초당 4회 확인합니다. 창의 제목 표시줄(위쪽 40pt)을 누르고
끄기 시작하면 전역 마우스 모니터(손쉬운 사용 권한 불필요)로 바로 감지해 눈을 미끄러뜨리고, 그 밖의 이동은 위 확인에서 감지합니다.

## Dock 위치 감지

- **손쉬운 사용(Accessibility) 권한**이 있으면 Dock의 실제 위치(AXList 프레임)를 2초마다 읽어 그 위에 눈을 쌓습니다.
  메뉴의 "Grant Accessibility for Dock snow"로 권한 요청 창을 띄울 수 있습니다.
- 권한이 없으면 `visibleFrame` 과 화면 하단의 차이로 Dock 높이를 구하고, Dock 설정(tilesize, 앱 개수)으로 너비를 추정합니다.
- Dock이 좌/우측이거나 자동 숨김이면 화면 하단을 바닥으로 사용합니다.

## 알려진 제한

- 화면 구성이 바뀌면(해상도/모니터 추가) 오버레이를 다시 만들기 때문에 쌓인 눈과 눈사람이 초기화됩니다 (선물과 전구 연결은 복원됨).
- ad-hoc 서명 앱이라 다시 빌드하면 손쉬운 사용 권한을 다시 허용해야 할 수 있고, Launch at Login 등록이 실패할 수 있습니다
  (실패 시 안내 창이 뜹니다).
- 권한 없이 추정한 Dock 너비는 실행 중인 앱 수에 따라 실제와 다를 수 있습니다.
- 바닥 눈 띠 위에서는 클릭이 오버레이로 가므로, 그 영역의 데스크톱 아이콘(또는 On Top 모드에서 그 위치의 창)은 클릭되지 않습니다.
- 가림 처리는 사각형 기준입니다 (둥근 모서리, 그림자, 메뉴/팝업 등 레이어 0이 아닌 창은 고려하지 않음).
